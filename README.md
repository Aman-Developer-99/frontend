# Web Development Learning Journey 🚀

This repository is dedicated to my journey of learning and mastering key technologies in front-end web development. The focus will be on four major areas: **HTML**, **CSS**, **JavaScript**, and **React**.

## 📚 What You'll Find Here

Each folder or section will contain focused content including notes, example projects, and hands-on exercises. The goal is to understand not just the "how," but also the "why" behind each concept.

### 🧱 HTML (HyperText Markup Language)
- **HTML Basics**
  - What is HTML?
  - Why do we use HTML?
  - Structure of an HTML document
  - Tags, elements, and attributes

- **Important Container Tags**
  - `<body>`: Main visible content of the webpage  
  - `<head>`: Metadata, links to stylesheets, scripts, etc.
  - `<div>`: Generic block-level container
  - `<p>`: Paragraph of text
  - `<article>`: Independent self-contained content
  - `<section>`: Thematic grouping of content
  - `<nav>`: Navigation links
  - `<header>`: Header for a page or section
  - `<footer>`: Footer for a page or section
  - `<aside>`: Sidebar or content related to the main content
  - `<a>`: Anchor tag for hyperlinks
  - `<ol>`, `<ul>`, `<li>`: Ordered and unordered lists
  - `<img>`: Display images

- **Styling and External Resources**
  - `<style>`: Add internal CSS styles
  - `<link>`: Link to external stylesheets
  - `<script>`: Add JavaScript, either inline or via external file

### 🎨 CSS (Cascading Style Sheets)
- CSS Basics
- How to include CSS in a webpage (inline, internal, external)
- CSS Selectors: `id`, `class`, `tag`, group, descendant, pseudo-selectors
- Common CSS Properties:
  - `padding`, `margin`, `font-size`, `color`, `height`, `width`, `background-color`
- Other CSS Properties:
  - `font`, `background`, `border`, `line-height`, `overflow`, `media-query`, `flex`, `grid`, `display`
- Focus styles, Hover styles, and Pseudo Classes like `:hover`, `:focus`, `:nth-child`, etc.

- How to include JavaScript in an HTML page

#### 📦 JavaScript Built-in Libraries

#### 🌀 Array & Object Utilities

### ⚛️ React

#### 🧠 React Basics
- What is React?
- Why use React?
- Core principles: components, JSX, virtual DOM

#### 🚀 Getting Started with React
- Include React library in a plain HTML page
- Write your first React component using vanilla setup

#### 🌐 React with Next.js
- Create your first React component using **Next.js**
- Understand the difference between Client-side and Server-side rendering
- Setting up routes and pages in Next.js

#### 🔁 Understanding Data Flow
- **State vs Props** – how data flows between components
- Introduction to `useState` and `useEffect` hooks

#### 📦 Creating a React Project
- Set up a boilerplate using `create-react-app` or `react-scripts`

- What is JSON (JavaScript Object Notation)?
- Rendering a list of records from static or dynamic JSON

#### 🔗 Advanced Concepts
- **Single Page Application (SPA)** – how routing works in React
- Using **React Router** to navigate between pages without reloading

#### 🧪 Mini Projects
- Build a **Google Search UI/UX clone** using mock API or mock JSON
- Create a **Next.js-based project** to explore SSR and API routes

#### ⚙️ React Hooks (Advanced)
- `useMemo` – optimize expensive calculations
- `useCallback` – memoize functions to avoid unnecessary re-renders
- `useContext` – access global state without prop drilling
- `useSelector` – extract state from Redux store
- `useRef` – reference DOM elements or store mutable values

## 🔥 Why This Matters

Understanding these technologies is crucial for building modern, efficient, and user-friendly web applications. By the end of this journey, I aim to have the confidence to build full-fledged frontend applications using React.
